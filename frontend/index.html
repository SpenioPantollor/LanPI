Link Event History

Logged whenever the TEST PORT's link state changes (up/down, speed, duplex) -- polled every 2s independently of the RX/TX counters above, so ordinary traffic never adds an entry. Resets when the backend restarts.

IP Conflict Detection

Passively watches ARP traffic on the TEST PORT -- an IP claimed by more than one MAC address at the same time is flagged here. A claim expires after 10 minutes of silence, so a genuinely resolved conflict (a device going offline, a lease changing hands) clears itself instead of lingering forever.

IP MAC addresses

DHCP Server Detection

Passively watches DHCP OFFER/ACK replies on the TEST PORT and lists every distinct server seen answering -- more than one is the actual rogue-DHCP symptom (clients getting leases from whichever server answers first), regardless of which one is "correct". No known-good server list is kept; judge which one doesn't belong yourself.
