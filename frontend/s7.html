CPU Identification

Sourced from eth0 — needs DHCP or Static mode. Connects over the S7comm/COTP handshake (TCP port 102, same as any S7 programming/HMI tool) and reads the CPU's own System Status List (module type, order number, firmware version, serial number, plant ID) — identification only. No process data (DB) read/write, no PLC start/stop — LanPi defaults to passive, non-disruptive diagnostics.

Read Tag

Reads one process-data value via S7comm's "Read Var" service (e.g. DB5.DBW10 or M0.3) — the S7 equivalent of a Modbus register read. Read-only: no write support.
